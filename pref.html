Browser Startup

When IINA starts, automatically open the standalone Emby browser window without needing to click the menu item or press Cmd+Shift+E.

Authentication & Session

Automatically extract server URL and API key from Emby URLs (like download links) and use them to auto-login to the sidebar browser. Server credentials are stored permanently until manually removed via the server management panel.

Media Playback

Automatically download external subtitle files when opening Emby media URLs in IINA. Subtitles embedded in the media file are not downloaded — IINA reads those directly from the file.

Replace the default filename with the actual movie/show title from Emby. Shows proper titles instead of generic "Download?ApiKey=..." names.

When playing media from Emby browser, open it in a new IINA window instead of the current one. This allows you to keep browsing while watching.

Report your playback progress to Emby while watching. Videos will be automatically marked as "watched" when you complete 95% of the content. This keeps your Emby library in sync with what you've watched in IINA.

When on, progress, resume and watched status are reported to the Emby account you logged into via the Emby browser sidebar — instead of the account whose api_key is in the playing URL. Ideal for Syncplay watch-togethers: everyone opens the same shared link, but each viewer's progress records into their own account. Requires being logged in via the sidebar; falls back to the URL's api_key if no account is connected.

Automatically reopen the Emby content browser when media launched from the browser finishes playing or its player window is closed.

TV Series Playback

When a TV episode ends, automatically play the next episode of the series if available. The player will create a playlist of all available episodes and play them sequentially.

Automatically skip the intro / opening theme when detected via Emby chapter markers or media chapters.

Automatically skip end credits and outro when detected via Emby chapter markers or media chapters. If autoplay is enabled, jumps directly to the next episode.

Audio & Subtitle Preferences

Remember the last chosen audio track (channel) and subtitle track for each movie or episode and across TV series when resuming playback.

Comma-separated list of preferred audio language codes (e.g., zh,chi,ja,jpn,en,eng).

Preferred channel layout when multiple audio tracks with the same language are available.

Comma-separated list of preferred subtitle language codes and variants (e.g., zh,chi,chs,sc,cht,tc,en).

Automatically activate the best matching subtitle track based on your preferred languages when playing media.

Subtitle Downloads

Comma-separated list of language codes to download (e.g., en,eng,pol,pl). Use ISO 639-1 (2-letter) or ISO 639-2 (3-letter) language codes.

Download every external subtitle track regardless of language preferences. When enabled, the preferred languages setting is ignored.

Notifications & UI

Display OSD messages when subtitles are downloaded or when errors occur.

Developer & Debug

Show detailed debug information in the console for troubleshooting. This will log parsing details, API responses, and other internal operations.
